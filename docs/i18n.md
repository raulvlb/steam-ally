# Internacionalização (i18n) - Steam Ally

## Visão Geral

O Steam Ally agora suporta múltiplos idiomas usando **react-i18next**. O sistema detecta automaticamente o idioma do navegador do usuário e exibe o conteúdo no idioma apropriado.

## Idiomas Suportados

- 🇺🇸 **Inglês** (en) - Idioma padrão/fallback
- 🇧🇷 **Português Brasileiro** (pt-BR)
- 🇪🇸 **Espanhol** (es)
- 🇫🇷 **Francês** (fr)
- 🇮🇹 **Italiano** (it)
- 🇩🇪 **Alemão** (de)

## Como Usar

### 1. Importar o hook useTranslation

```tsx
import { useTranslation } from 'react-i18next';
```

### 2. Usar o hook no componente

```tsx
export function MyComponent() {
  const { t } = useTranslation();
  
  return (
    <div>
      <h1>{t('section.key')}</h1>
    </div>
  );
}
```

### 3. Chaves de Tradução

As chaves de tradução estão organizadas em categorias nos arquivos JSON em `src/locales/`:

- `site.*` - Informações do site
- `nav.*` - Navegação
- `home.*` - Página inicial
- `games.*` - Página de jogos
- `achievements.*` - Página de conquistas
- `guides.*` - Biblioteca de guias
- `guide.*` - Editor e visualização de guias
- `profile.*` - Página de perfil
- `common.*` - Textos comuns (botões, etc)
- `pagination.*` - Paginação

### 4. Interpolação de Variáveis

Para usar variáveis nas traduções:

```tsx
// No arquivo de tradução:
{
  "welcome": "Welcome, {{name}}!"
}

// No componente:
<p>{t('welcome', { name: userName })}</p>
```

### 5. Pluralização

Para contadores:

```tsx
// No arquivo de tradução:
{
  "entries": "{{count}} entries",
  "entry": "{{count}} entry"
}

// No componente:
const count = guide.entries.length;
<p>{count === 1 ? t('guides.entry', { count }) : t('guides.entries', { count })}</p>
```

```
│   ├── fr.json               # Francês
│   ├── it.json               # Italiano
│   └── de.json               # Alemão
```

## Adicionar Novas Traduções

1. Adicione a chave em todos os arquivos de idioma em `src/locales/`
2. Use a chave no componente com `t('category.key')`
3. Teste em diferentes idiomas alterando o idioma do navegador

## Detecção de Idioma

O idioma é detectado automaticamente na seguinte ordem:
1. Idioma do navegador (navigator.language)
2. Idioma salvo no localStorage
3. Idioma da tag HTML
4. Fallback para inglês (en)

## Mudança Manual de Idioma

Se você quiser adicionar um seletor de idioma:

```tsx
import { useTranslation } from 'react-i18next';

function LanguageSelector() {
  const { i18n } = useTranslation();
  
  return (
    <select value={i18n.language} onChange={(e) => i18n.changeLanguage(e.target.value)}>
      <option value="en">English</option>
      <option value="pt-BR">Português</option>
      <option value="es">Español</option>
      <option value="fr">Français</option>
      <option value="it">Italiano</option>
      <option value="de">Deutsch</option>
    </select>
  );
}
```

## Exemplo Completo

```tsx
import { useTranslation } from 'react-i18next';

export function ExampleComponent() {
  const { t } = useTranslation();
  const userName = "John";
  const count = 5;
  
  return (
    <div>
      <h1>{t('home.title')}</h1>
      <p>{t('home.welcome', { name: userName })}</p>
      <p>{t('games.achievements', { count })}</p>
      <button>{t('common.save')}</button>
    </div>
  );
}
```
